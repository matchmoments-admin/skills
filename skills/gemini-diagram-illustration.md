# gemini-diagram-illustration

Generate fully-illustrated Excalidraw diagrams: hand-drawn sketches (or any chosen style) generated by Gemini, then composed with arrows and labels into a single self-contained `.excalidraw` file with images embedded as base64. Drag the file into excalidraw.com — no external assets to track.

The point is to take a blog draft / script / explainer and turn it into a cohesive illustrated flowchart in 1–3 minutes instead of an hour, by issuing all illustration calls in **parallel** and letting a Python helper do the boring base64 packaging.

This skill is the illustration-heavy companion to `excalidraw-diagram` — use that one when you want clean shape-and-arrow diagrams, this one when you want hero illustrations baked into the composition.

## Usage

```
/gemini-diagram-illustration <topic-or-source-path>
  [--mode collab|auto]            # default: collab — pause for approval at each pipeline stage
  [--source <path>]               # explicit blog draft / script file; otherwise auto-discover newest .md
  [--source-dir <dir>]            # directory to search for newest .md (default: cwd)
  [--style <name>]                # default: sketch — see image_prompt_templates.json
  [--segments <n>]                # default: agent decides (3–7); cap segments to keep diagrams scannable
  [--output <path>]               # default: ./diagrams/<slug>.excalidraw
  [--layout <name>]               # default: linear-flow — linear-flow|circular|grid|two-column
  [--keep-pngs]                   # keep the intermediate PNGs alongside the .excalidraw (default: deleted after embedding)
```

## The 5-stage pipeline (in brief — workflow.md has the detail)

1. **Initialize** — locate the source content, load `image_prompt_templates.json`, pick the style, decide output path.
2. **Plan** — segment the content into 3–7 visual beats, draft a hero-illustration prompt for each. In `--mode collab`, show the user the prompts and segment plan and wait for approval.
3. **Illustrate** — issue **all** Gemini image-generation calls in a single message (parallel tool calls in Claude Code) so wall-time scales with the slowest single call, not the total. Save PNGs to a temp dir.
4. **Compose** — write a spec file describing each image's position, label, and the arrows/text linking them, then run `compose_excalidraw.py` to bake it into a single `.excalidraw` file with base64-embedded images.
5. **Export & polish** — print the output path. In `--mode collab`, prompt the user to open it at excalidraw.com; in `--mode auto`, just report the path.

## Modes

- **`collab`** (default): the agent stops before any "CRUD"-shaped operation that could surprise the user — generating images (cost money), writing the final file (overwrites), deleting the temp dir. Each stop shows what's about to happen and waits for "ok" / a correction.
- **`auto`**: the agent runs the entire pipeline without stopping. Good for re-runs after you've already nailed the prompts in collab mode, or for batch processing several drafts.

The user picks the mode per invocation. Default is `collab` because the cost of a misfire (5–10 wasted Gemini calls) is more annoying than the cost of one extra confirmation.

## Why two skills?

- **`excalidraw-diagram`** — when the diagram is *abstract*: architecture maps, comparison tables, evidence-to-verdict flows. Output is shape + arrow + text, palette-disciplined, validated with a Pillow render → critique loop. Cheap, fast, no API spend.
- **`gemini-diagram-illustration`** — when the diagram is *narrative*: "here's what a user does, here's what our system sees, here's what comes back." Output is illustration-heavy, embeds Gemini-generated hero images, costs Gemini API credits per run.

Pick the one that matches the content shape. If unsure, draft a quick `excalidraw-diagram` first, then upgrade to `gemini-diagram-illustration` if the post is going on the front page or in marketing.

## Output

A single `.excalidraw` file. The user opens it by:

- Drag-and-drop onto <https://excalidraw.com>, or
- Open in the Obsidian Excalidraw plugin.

Because the images are embedded as base64 in the JSON's `files` map, the file is fully self-contained — moving it to a different machine or sharing it works without the receiver needing the original PNGs.

## Notes

- This skill assumes `mcp__gemini__gemini-generate-image` is available. If it's not, the skill should bail at stage 3 and report which MCP tool is missing.
- Gemini image-gen costs real money per call. The skill caps segments at 7 by default; bump with `--segments` only when the content genuinely needs it.
- Adam Goodyer's original "Gemini-Diagram-Illustration" skill (the inspiration here) uses raw HTTP calls to Gemini. We use the existing `mcp__gemini__*` MCP tools instead since they're already wired up — same model under the hood, no extra API key handling.
- The `excalidraw-diagram` skill's `render_diagram.py` can render the output of this skill too — image elements show as placeholder rectangles in the preview, which is enough to validate layout before opening the real file.
